Most people type a one-line question into an AI tool, get a mediocre answer, and conclude "AI isn't that useful." The tool isn't the problem. The prompt is.

## The fix: treat every prompt like a briefing, not a search query

When you brief a person, you naturally give them context: who this is for, what "good" looks like, what to avoid. Do the same for AI.

A weak prompt:

```
Write a product description for my coffee shop.
```

A strong prompt:

```
Write a product description for a specialty coffee shop in Nairobi.
Audience: young professionals who care about quality, not price.
Tone: warm but not cheesy — no "indulge yourself" clichés.
Length: 60-80 words.
Include: single-origin beans, locally roasted, free wifi.
```

Same tool, dramatically different output — because you gave it the same context you'd give a human.

## Three questions to ask before every prompt

1. **Who is this for?** The AI can't guess your audience.
2. **What does "good" look like?** Give it an example or a tone reference if you can.
3. **What should it avoid?** Naming the failure mode (generic, corporate, too long) is often more useful than describing success.

## Try it now

Take the last prompt you wrote that gave you a disappointing result. Add answers to those three questions and run it again. That's the whole skill — everything else is refinement.
